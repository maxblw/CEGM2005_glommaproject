Project repository for the Glomma project as part of CEGM2005 - MORE (Probabilistic Modelling of Real World Phenomena Using Observation and Elicitation)

For the used data, please see the "Data" file, this contains both the raw data and the processed data, with exception of the snowpack datafiles, which where excluded due to their size.

The vinemodel is defined in the file "Model", subdivided in preprocessing of the data in the notebook "correlations.ipynb" and the fitting and conditionalizing of the model in the notebook "vine_model.ipynb". Several helper functions are defined in the scripts "functions.py" and "model_functions.py"

The expert judgment model is defined in the file "ExpertJudgment", which contains the notebook used to process the results of the questionare "Expertjudgment.ipynb" and the actual questionare results in "Resultaten.xlsx"
